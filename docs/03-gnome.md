# 03 — GNOME

Install the core desktop tools:

```bash
sudo pacman -S --needed \
  gnome-shell \
  gnome-control-center \
  gnome-tweaks \
  gnome-keyring \
  nautilus \
  file-roller \
  xdg-user-dirs \
  gnome-extensions-app
```

Keep GNOME extensions minimal and review them after GNOME upgrades.

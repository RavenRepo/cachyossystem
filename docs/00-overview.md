# 00 — Overview

This repository is organized as a workstation lifecycle:

1. Install CachyOS.
2. Update the system.
3. Install baseline tooling.
4. Configure GNOME.
5. Configure Git/GitHub.
6. Install the development stack.
7. Install AI tooling.
8. Install editors and browsers.
9. Install databases and containers.
10. Configure private networking.
11. Harden the machine.
12. Install productivity/media software.
13. Verify.
14. Maintain.

The README is the primary entry point. These files provide phase-specific detail.

## Design principle

Prefer official repositories over AUR when both are suitable. Use upstream installers for fast-moving AI tools when their official documentation recommends them.
